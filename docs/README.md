# OddsIQ docs

This folder is an Obsidian vault and the knowledge base for OddsIQ.

## Quick orientation

1. Read [`00 - Map of Content.md`](00%20-%20Map%20of%20Content.md) (the MOC) first.
2. Read the relevant component, operations or roadmap pages as needed.

Untagged docs under `Architecture/`, `Components/`, `Operations/`, `Validation/`, `Roadmap/`, `Decisions/`, `Testing/` and `Legal/` are canonical. `Design/` holds dated design specs for shipped work: design context, not the canonical description of the current code.

`Known Issues/Fixed - *.md` and `Production/First Game Night.md` are historical post-mortems, kept because canonical pages cite them for rationale.
